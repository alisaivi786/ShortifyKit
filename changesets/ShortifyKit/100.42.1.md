# ShortifyKit 100.42.1

Date: 2026-10-01
Type: Minor

## Changes
- Version aligned with the NinjaVault SDKs (`NinjaVault.Cdn`, `NinjaVault.Http`): all are now 100.42.1.
- No code changes since 1.0.0.

## Why
- One version number across the company's .NET SDKs, so a consumer can tell at a glance that the packages
  were released together. 100.42.1 sorts after 1.0.0 on NuGet, so `dotnet add package ShortifyKit` picks it up.

## Breaking Changes
- None.
