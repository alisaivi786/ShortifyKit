# ShortifyKit 1.0.0

Date: 2026-10-01
Type: Major

## Changes
- First release: `IShortifyClient`, registered with `AddShortify(configuration)` or `AddShortify(options => ...)`.
- Links: create (with an `Idempotency-Key` on every call), bulk create, get, list/search/filter, edit (PATCH with
  optimistic concurrency), pause/resume, delete, per-link analytics.
- Account: overview (`/me`), usage with daily history, account-wide analytics, plans.
- Branded domains: list, add (returns the TXT/CNAME records), verify, delete.
- `ShortifyApiException` carries the status, `ErrorCode`, `Details`, `TraceId` and `Retry-After`, with
  `IsPlanLimitReached`, `IsPlanUpgradeRequired` and `IsRateLimited`. Non-envelope responses (proxy pages) map to
  it too, never to a bare `JsonException`.

## Why
- A supported, versioned way for customers' .NET backends to call Shortify, in the same shape as `NinjaVault.Cdn`.

## Breaking Changes
- None (first release).
